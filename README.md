# 아지트 내전 모집 봇

## 1. 설치
1. Python 3.10 이상 설치 (설치할 때 "Add Python to PATH" 체크)
2. 이 폴더에서 명령 프롬프트를 열고:
   ```
   pip install -r requirements.txt
   ```

## 2. 디스코드 개발자 포털 설정
- Bot 탭 → **SERVER MEMBERS INTENT** 켜기 (필수)
- OAuth2 → URL Generator → scopes: `bot`, `applications.commands`
- 봇 권한: 메시지 보내기, 링크 첨부(Embed Links), 메시지 기록 보기, **모든 역할 멘션하기**(티어 역할/관리자 호출 핑용), **역할 관리**(뉴비 역할 자동 회수 및 /뉴비정리용)
- 봇 역할을 서버 역할 목록에서 **'뉴비' 역할보다 위**로 올려주세요.

## 3. 토큰 / config.py 채우기
- `.env.example` 을 복사해서 이름을 **`.env`** 로 바꾸고 `DISCORD_TOKEN`, `GUILD_ID` 입력
  (`.env` 는 `.gitignore` 에 들어 있어서 GitHub에 올라가지 않아요. 토큰은 절대 config.py에 직접 쓰지 마세요.)
- `CANCEL_LOG_CHANNEL_ID` 또는 `CANCEL_LOG_CHANNEL_NAME` – 취소 명단이 자동으로 올라갈 관리자 채널
- `MOBASHI_CHANNELS` (A~E 신청방 / 대기방 ID), `LOW_CHANNELS`, `HIGH_CHANNELS`
- `STATUS_CHANNEL_ID` (내전-모집-현황 채널)
- 안내 문구는 config.py 아래쪽 `GUIDE_...` 항목에서 바로 수정할 수 있어요.

> 채널 ID 복사: 디스코드 설정 → 고급 → 개발자 모드 ON → 채널 우클릭 → "채널 ID 복사"

## 4. 실행
```
python bot.py
```
`naejeon.db` 파일에 전적, 진행 중인 모집, 취소 명단이 저장돼요. **이 파일을 지우면 전적이 사라집니다.**
봇을 껐다 켜도 진행 중인 모집글 버튼은 그대로 작동해요.

## 5. 흐름
1. `/모바시내전모집` (진행방식) 또는 `/저티어내전모집`, `/고티어내전모집` (모집유형, 진행방식, 예약이면 모집시간)
   → 모집글 생성 + 내전-모집-현황 채널에 "#채널 모바시 3판2선 내전 인원 모집 중" 메시지
2. 참가/대기 버튼 → 신청한 순서대로, 티어 색상 · 전적 · 신청 시각 표시, 주라인 집계
   - 20:00 이후 취소 / 8명 이상 모였을 때 취소 → 모집글의 **📝 취소 기록** 칸 + 관리자 채널에 자동 기록
   - 예약 시간은 `22:00`, `22시`, `오후10시` 처럼 입력 (`10시` 는 오전 10시)
3. 10명이 모이면 모집글이 삭제되고 **참여자 티어 정보**(티어 높은 순, 대기자는 아래)가 올라와요.
4. **팀 입력하고 경기 시작** → 표에서 줄을 복사해 1팀 5줄 / 2팀 5줄을 붙여넣기. 각 줄 끝 사용자 ID를 함께 복사하세요. 기존 버전 게시글은 /내전현황으로 새로 띄울 수 있어요.
   → 경기 진행 중 메시지 + 모바시 전용 채널에서 시작했다면 다음 빈 신청방에 같은 진행 방식으로 자동 모집 (A→B→C→D→E→A)
5. **1팀/2팀 최종 승리** → 전적 자동 반영, 결과 메시지로 바뀜. 3판2선은 시리즈 최종 결과를 1승 또는 1패로 기록합니다.

- 모바시·저티어·고티어 내전 전적을 합산하며, 결과 기록 시 누적 3판(승+패) 이상인 경기 참가자의 `뉴비` 역할을 자동 회수해요. 봇에 **역할 관리** 권한을 주고 봇 역할을 `뉴비`보다 위에 배치하세요. 기존 전적으로 3판 이상인 멤버를 일괄 정리하려면 `/뉴비정리`를 실행하세요.
- 정원이 차면 새 티어 게시글에서 대기 신청과 신청 취소를 할 수 있어요. 참가 취소 시 대기 1순위를 자동 승급하고, 대기자가 없어 9명이 되면 모집을 다시 열어요.
- 저티어·고티어는 정원 마감 후 **관리자 호출**로 관리자·보조관리자 역할을 멘션할 수 있어요.
- 예약 내전은 입력한 한국 시각의 경기 시작 시간을 표시하고, 10분 전 대기실 집합을 안내해요. 모집글은 명령어를 실행하면 바로 올라갑니다.
- 취소 기록 시간대의 기본값은 한국 시각 20:00~다음 날 06:00 직전입니다. 8명 이상일 때 참가를 취소하면 시간과 상관없이 별도로 기록됩니다.

## 6. 명령어
| 명령어 | 권한 | 설명 |
|---|---|---|
| /모바시내전모집 | 관리진 | 모바시 채널(A~E)에서 모집 시작 |
| /저티어내전모집, /고티어내전모집 | 관리진 | 모바시/예약 선택, 티어 역할 자동 언급 |
| /강제취소 | 모집자·관리진 | 잠수/탈퇴 유저 명단 제외 (취소 명단엔 기록 안 함) |
| /내전현황 | 모두 | 현재 모집글을 채팅창 아래에 새로 띄우기 |
| /내전모집취소 | 관리진 | 이 채널의 모집/경기를 기록 없이 닫기 |
| /전적, /순위 | 모두 | 전적 조회 / 승리 수·승률 랭킹 |
| /전적수정, /전적초기화 | 관리진 | 전적 직접 수정 / 0승 0패 |
| /뉴비정리 | 관리진 | 3판 이상 유저의 뉴비 역할 회수 |
| /취소명단 | 관리진 | 취소 기록 조회 |
| /주사위 | 모두 | 1~6 |

"관리진" = config.py의 `STAFF_ROLE_NAMES` (관리자, 보조관리자, 매니저).


## 7. GitHub에서 Railway에 배포하기

1. ZIP을 풀고 `naejeon_bot` 안의 파일을 GitHub 저장소 루트에 올려요. 하위 폴더로 올렸다면 Railway 서비스의 Root Directory를 `/naejeon_bot`으로 설정해요.
2. Railway에서 해당 GitHub 저장소를 서비스에 연결하고, Variables에 `DISCORD_TOKEN`과 `GUILD_ID`를 입력해요. 채널 ID는 `config.py`에 채우거나 `.env.example`에 적힌 이름으로 Railway Variables에 입력해요. 채널마다 서로 다른 텍스트 채널 ID를 사용하세요.
3. 서비스에 Volume을 붙이고 Mount Path를 `/data`로 지정해요. 기본 DB 경로는 `/data/naejeon.db`가 됩니다. 기존 DB가 있다면 봇을 끈 상태에서 그 DB를 Volume에 옮긴 뒤 기동하세요. 기존 마운트 위치를 유지한다면 DB가 실제로 있는 경로에 맞춰 `DB_PATH`를 설정할 수 있어요.
4. 저장소의 Dockerfile이 `python bot.py`로 시작하고 `railway.toml`은 인스턴스 1개를 설정해요. 예전에 입력한 Start Command가 있다면 지우거나 `python bot.py`로 맞춰 주세요. 디스코드에 연결하는 워커라 공개 도메인은 필요 없어요.
5. 로그에서 로그인 완료를 확인한 뒤 서버에서 모집 명령어를 실행해요. 역할 이름과 신청방 ID, 봇의 채널 보기·메시지 보내기·임베드·메시지 기록 읽기 권한을 확인하세요.
